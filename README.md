# SA-MP Drop Gun System

A simple weapon dropping and pickup system for SA-MP roleplay servers.

![Drop Gun System Preview](https://raw.githubusercontent.com/MartinSAMP/dropgun-samp/blob/main/sa-mp-096.png)

## Features

- Drop current weapon with /dropgun command
- Pickup weapons by pressing Y key near dropped items
- 3D object visualization for dropped weapons
- 3D text labels showing weapon name and ammo count
- Automatic roleplay messages for drop/pickup actions
- Proximity-based messaging (20 meter radius)
- Supports common weapons (pistols, shotguns, SMGs, rifles)
